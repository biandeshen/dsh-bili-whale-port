# BGM —— CC0 公共领域曲库（本地视频用）

本目录的 mp3 全部来自 **AERIS MUSIC** 的 CC0 曲库，公共领域，可商用、可修改、无需署名。

- 来源：https://github.com/farmmer938-lgtm/aeris-cc0-music
- 许可：CC0 1.0 Universal（见 `LICENSE-CC0.txt`）
- 入库日期：2026-10-30

| 文件 | 曲目 | 情绪/速度 | 时长 |
|---|---|---|---|
| `bedroom-window-outlands.mp3` | Bedroom Window (Outlands) | lofi / calm，74 BPM | 58s |
| `quiet-room.mp3` | Quiet Room | ambient / calm，68 BPM | 57s |
| `colder-air.mp3` | Colder Air | dark / cold | 55s |

用法：`node tools/video-build.mjs --bgm quiet-room ...`，或 `--bgm auto`（默认第一首），`--bgm none` 关掉。
