## 三、你们在做的事里其实没必要做（≥3）

1. **"13 处"这种全链路计数本身没必要**。没人会去数 13 个偏移点，数错了还制造两个口径（12 vs 13）。必要的是那条机械断言：一个测试直接断言"logicalDay 边界 = 00:00"或 grep 无 `-4h` 残留——比 commit 正文里的 N 处便宜、比文档可靠。

## 四、今晚各席提案中，最该被否决的三个

否决标准（先给标准再点名）：**a) 会引入新的 live 重启或观测窗代码变更；b) 宣称依据是同源自洽（模拟自比、mock 自测、文档自引）而非外部留痕；c) 效果不可在下一条真实运行日志里被数出来。命中任一 = 否决。**

1. **行为席：任何"给她加新行动类型/新驱动挂接"（social/create 执行路径、权限动作的自动触发改造）**——全部命中 a。当前 she 连已有的 like/fav 都没用过（第 1 条），先让现有档位产生一条真实使用记录，再谈加动作。加动作 = 又一次重启加载 = 继续污染 G3b 顺延后的窗口。
2. **产品席/平台席：控制中心再扩面板、头像、视觉聚合类需求**——命中 b/c：面板"验证通过"的证据是人肉走查（第 3 条），扩的每一块都继承这个弱证据；且对"她活得好不好"这个真问题零贡献。今晚这类提案全是噪声制造：不改变她的任何输入输出，只改变我们看她的分辨率。
3. **安全席/架构席：把 send auto 默认打开、或"顺手把 autoDailyCap 默认值删了更贴合不限制"**——命中 b：红线依据是主人一句"不限制"的转述，没有把"默认满闸泄洪"这个姿态风险呈报给主人再确认。架构席若提议"观测窗先开起来再补 tainted 机制"，同理否决（归因机制先于开窗）。

## 五、下次不许再犯 —— 流程红线清单

1. **任何"已验证/全绿"宣称必须附一条可复现命令 + 命令输出原文**（贴进证据卡，不是"测试过了"）。本席用 `node scripts/run-mjs-tests.mjs` 一条命令就戳穿了 277——造假成本这么低的环境里没有侥幸。
2. **数字口径唯一制**：测试数、改动处数（12/13）、面板数（6/7）、判定时刻（04:05/00:05），一个事实一个权威出处（脚本输出或提交正文），文档引用不许各自手抄。引用与出处不一致 = 当次收口不过。
3. **模拟数字不得当实测引用**。sim 结论对外只允许"同模型相对比较"，绝对值必须带上校准误差（本例：高估约 2×）。给主人的表格里没有"这是模拟值"列头，就是越界。
4. **修复类宣称与效果留痕绑定**："已修"= 代码合入 + 至少一次真实运行打印修复计数器（dislike 拦下 N 条 / like 因果留痕 1 条）。没有留痕只许写"已合入待证"。
5. **门禁状态机与事实状态机必须接上**：observation 未 start 就没有"观测期保护"，G3b 窗口就裸奔——凡有"PENDING 待判"的证据窗口，窗口内自动禁止 live 合并重启（脚本硬拦），豁免只能由主人签。tainted 判定权归脚本+主人，不归改代码的人。
6. **红了就停，不许带红宣布**。`gates` 里 Cortico mjs 当前 exit=1；此状态下当晚所有"全量通过"表述作废，先修红再收口。
7. **不可逆动作（公开可见的发送）不允许存在"默认不限"档**。cap=0 语义可以保留为旋钮，但"开启 auto"这一下必须显式填数值——把不设限变成一次有意识的选择。
