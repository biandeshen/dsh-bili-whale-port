# D-32 行动账本对账 —— 证据（2026-10-29）

> 范围：并发实例把 `control/life.json` 的 `actionsToday` 覆盖回 0，导致观测少记行动/唤醒。
> 做法：行动本来就写 append-only `causal.jsonl`，启动时按逻辑日对账，**只增不减**。

## 1. 改动

| 文件 | 改动 |
|---|---|
| `Cortico/src/worlds/bili-account/definition.ts` | 新增导出 `countCausalActions(file, day)`；`start()` 里 `actionsToday = max(life, causal)`、`lastActionAt = max(...)`，并落盘 |
| `Cortico/tests/causal-ledger.test.mjs`（新） | 3 例：只数 `kind=action` 且属该 04:00 日界；坏行/缺 `atMs` 跳过；文件缺失按 0 |

判定口径：`dayKey(atMs) === day`，即 **04:00 日界**；`watched` / `diary` / `draft-result` 不算行动。
读失败按 0 处理，不阻止启动；实现见 `definition.ts` 的 `countCausalActions`。

## 2. 验证

```
cd Cortico && npx tsc --noEmit          # exit 0
cd dsh-bili-whale && node scripts/run-mjs-tests.mjs --root ../Cortico --import tsx
# tests 103 / pass 103 / fail 0 / EXECUTED=12
```

重启实测（03:34）：

```
POST /api/run/shutdown   # 五步全 ok
node scripts/start-cortico.mjs
cat control/life.json
# day=2026-10-28 actionsToday=0 lastActionAt=1793197282292（22:21 那次，未被清零）
node scripts/cortico-health.mjs   # 健康检查通过
```

当前 `causal.jsonl` 里还没有 `{kind:'action'}` 记录（补写逻辑上线晚于 22:21 那次行动），
所以本次重启对账结果为 0 是正确值；下一次自然行动会写第一条，届时可复核。

## 3. 边界

- 只修**记账**，不修**并发写**：写锁仍是 D-18（多实例、多状态根、0 锁），根因未复现。
- 对账只增不减：即使 `life.json` 被旧实例覆盖，重启后也会回到因果链的真实条数。
- 同一天多次重启不会重复计数（取 max，不是相加）。
