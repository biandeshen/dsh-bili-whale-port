# M3 私信回信路径（审批门内）—— 证据（2026-10-29）

> 范围：M3 剩余项「私信回复路径」。她只能**写草稿入队**，发送必须主人拿一次性 token 显式 `--go`。
> 不新增自动发送，不改变 `dm.mjs` 的“只发主人 / 必须互关 / 每天锁定 1 个收信人”约束。

## 1. 链路

```
她醒来 → bili_dm_read 命中（只读，不标已读）
        → life.lastInboundKey / lastInboundAt（只存 key，不存正文）
        → bili_dm_reply {text}            # 只入队，不发送
        → ~/.dsh/bili-whale/control/dm-drafts.json + ack 一次性令牌（12h）
主人   → node scripts/dm-approve.mjs list                     # 打印完整 token
        → node scripts/dm-approve.mjs approve <id>            # dry：只跑 dm --dry
        → node scripts/dm-approve.mjs approve <id> --token … --go
```

## 4. 边界与残留

- **真实发送未做端到端**：需要主人先发一条私信、她再写草稿、主人再审批；当前信箱为空，不造假消息。
- `bili_dm_reply` 只校验“最近 7 天内读到过他的信”；内容是否得体由主人审批把关。
- 回信成功写 `causal dm-sent`，**不**直接改场值；情绪影响仍只走 `bili_mood_apply`，避免双重记账。
- 私信写接口仍是 `dm.mjs` 的专属通道（只发主人、必须互关、一天锁 1 人）；本路径没有放宽。
- 不 `--mark-read`；`bili_dm_read` 仍是只读 + 本地游标。
