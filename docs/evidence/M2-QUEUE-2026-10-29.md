## 4. 未覆盖 / 风险

- 投递语义是 **at-least-once**：推送成功后、标记 delivered 前崩溃，会在重启时重放一条提示；提示不是写操作，可接受。
- 没有实现 spec 里的 claim/backoff/recurring 调度：宿主 `setTimeout` 仍是节拍器，队列只保证"意愿不丢"。
- forced 轮改动未做真实运行验证（需要 `BILI_ACCOUNT_FORCE_ACTION=1` 起服务并触发一轮模型回合）；逻辑是"只写 manualForcedAt"，由代码审查与类型检查背书。
- `queue.json` 的并发写者仍只有 World 进程（lifeTick 与 boot 都在同一进程内串行 await），暂不需要锁。
