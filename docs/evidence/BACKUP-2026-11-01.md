## 用法（每日）

```bash
npm run ops:backup                     # 默认 <whale home>/backups/，env WHALE_BACKUP_DIR 或 --to 覆盖
node scripts/ops-backup.mjs --restore <备份目录>            # 只报告，不写盘
node scripts/ops-backup.mjs --restore <备份目录> --apply    # 真写；写前当前状态另存 pre-restore-<ts>/
```

真写后逐文件 sha256 校验，不一致即失败退出；`--apply` 不是裸覆盖——先另存，退得回去。
