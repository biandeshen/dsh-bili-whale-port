## 2. 六席裁决

| 席 | 主张 | 被采纳/驳回 |
|---|---|---|
| 产品席 | 她"像不像一个人"取决于身份事实是否每轮都在场；英文种子说"answer plainly"，会把她压回客服腔 | 采纳：身份事实进 CONSTITUTION |
| 架构席 | 按关注点拆分：身份 vs 流程。禁止软链/双写（跨盘、用户数据、Windows 权限，脆弱） | 采纳 |
| 运行席 | DSH 时钟已停用，persona.md 不是活路径；但面板仍能编辑它，必须现场警告 | 采纳：文件头警告 + 文档 |
| 安全席 | 铁律允许两处重复（纵深防御）；身份事实只写一处 | 采纳 |
| 挑刺席 | "ORIENTATION 里还留了一行身份"仍是漂移源；建议删掉 | **部分驳回**：模型每次醒来第一段需要最简称呼锚点；限定为"只允许称呼行，详细一律指 CONSTITUTION"，并加机器门 |
| 记录席 | 改宪法=改人格，必须可回滚、有前后哈希、有活取件 | 采纳：备份 + 哈希 + `/api/prompts/prefix` 实测 |
