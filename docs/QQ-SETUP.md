# QQ 接入指南（给主人，2026-11-06）

她的 QQ 通道已经挂上（7799 日志里 `World 已启动: qq`），现在只差一个协议端。
整套分两半：**她这边（已就绪）** ↔ **NapCat 协议端（要你装，约 10 分钟）**。

## 为什么要用小号

NapCat 是第三方协议端，QQ 官方不允许机器人挂普通号。**主号有封号风险**，
多方提醒过——用你专门注册的 QQ 小号登录 NapCat，她的身份就是那个小号。
你自己的大号加她好友、拉群，不受影响。

## 步骤

1. **装 NapCat**：去 NapNeko/NapCatQQ 的 GitHub Releases 下 Windows 一键包
   （NapCat.Shell / 一键启动包），解压到任意目录，扫码登录你的 QQ 小号。
2. **开正向 WS**：NapCat 的 WebUI 里新建网络配置 → WebSocket 服务器（正向 WS），
   监听 `127.0.0.1:3001`，设一个 access token（随便一串字符，别用弱口令）。
3. **到她的控制台接线**：开 http://127.0.0.1:7799/ → QQ 面板 → 连接设置：
   - WS 地址填 `ws://127.0.0.1:3001`
   - token 填上一步设的同一串
   - 保存后它会自动重启连接；日志里「身份就绪」即接通。
4. **加名单**：同一个面板里把你的大号 QQ 号加进「私聊名单」（启用），
   想让她进哪个群就把群号加进「群名单」。**名单外的会话她既不收也不发。**

## 接通之后她是什么样

- 你在 QQ 上给小号发私聊 → 事件进来叫醒她，她像 B 站私信一样回你（起草后确认发出）。
- 群里需要 @她 才投递；私聊一律投递。
- 发消息走的是「起草 → 确认」两步门：她每次真发之前自己过一遍。
- 图片/语音：消息里的图会下载存档；配了 OPENROUTER_API_KEY 才会自己看图，没配也能收发文字。
