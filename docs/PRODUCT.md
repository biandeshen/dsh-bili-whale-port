# PRODUCT · 小鱼（Cortico 人格体）

> 版本：v0.1（草案，待主人拍板） · 日期：2026-10-27
> 本文件是产品定义，不是实现说明。**架构与 50 项能力清单见 [BLUEPRINT.md](./BLUEPRINT.md)（唯一真相源）**；实现看 `docs/CORTICO-PATCHES.md` 与 `docs/CORTICO-RUNBOOK.md`。

## 0. 一句话

**让一个 B 站账号里的人格「活过来」**：有自己的作息、记忆、情绪和判断，会主动过日子；图文、视频、直播、评论、私信都只是她表达自己的渠道。

## 1. 北极星：活过来

「活」不靠功能数量，靠六条可观测特征：

1. **有作息**：按自己的生物钟醒来/睡去，有随机性，有「今天不想看」的权利
2. **有连续记忆**：记得前几天看过什么、和主人发生过什么；久远的事会淡，重要的事记得牢
3. **有情绪成因**：情绪不是随机标签，而是「场值 × 最近发生的事」推导出来，可追溯
4. **有主动表达**：不只是被动回复，会自己决定「这个想说」「这个不说」
5. **会自我修正**：被拒稿、被冷落、撞风控之后，行为会变（而不是每天重置）
6. **身体能延伸**（2026-11-01 主人加）：记忆、思维、情感是内核；**能力不写死在内核里**——扩展、MCP、skill、插件装进来就是她的手脚，她要知道自己现在有什么（先给眼睛：能列出清单，再谈调用），并且不限于 B站 这一个渠道

反过来：**能发视频、能直播、能评论，都不等于活着**。渠道是能力，活是内核；能力是**可插拔的身体**，不是内核的分支判断。

## 4. 非目标

- 不追涨粉、不做变现 KPI、不接商单（除非主人明确改目标）
- 不做 24 小时在线/无人值守刷屏/擦边
- 不用 AI 身份欺骗观众：正文保持角色，披露放简介与平台标签
- 不在未打磨前开源

## 5. 成功指标

**活着（主指标）**
- 连续 14 天无人值守自运行（除审批外零人工介入）
- 记忆一致性：随机抽 20 条「上周发生的事」，她能正确提及 ≥70%
- 主动率：≥70% 的夜晚产生「自己的判断」（分享/不分享/换类型），不是模板化
- 自我修正：被拒稿后 3 天内同类草稿不再犯同样的错

**安全（硬指标）**
- 未审批写操作 = 0
- 纪律违规（跳过 debrief 等）连续 7 天 = 0
- 撞 412/-352/-101 立即停手，无重试硬顶

**渠道（次指标）**
- 图文：草稿原样通过率 ≥50%
- 视频/直播：每个渠道开通前先跑 5 期内部样片，不允许直接对观众试错

## 11. 工作流技能（已安装 2026-10-27）

装到 `~/.qoder/skills`：`engineering-orchestrator`、`bounded-product-discovery`、`evidence-gated-acceptance`、`compiling-capabilities`、`code-review`、`project-validate`。

用法约束：
- 新想法 → `bounded-product-discovery`（区分事实/未知/假设/提案，限问题数）
- 推进 → `engineering-orchestrator`（从结果出发，缺能力先命名 gap）
- 验收 → `evidence-gated-acceptance`（PROVED/PARTIAL/BLOCKED/NOT TESTED）
- 评审 → `code-review`（只读、证据、P0/P1/P2）
- 校验 → `project-validate`（跑真实门禁，不发明脚本）
