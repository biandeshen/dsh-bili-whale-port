## 1. 目标要不要调？——不调

目标 = G3b（canary 3/3）+ 14 天观测 + "过完一天"证据。逐项对账：
- canary C1/C3 已 PASS；C2 是真实离线恢复，**这是"她能在断电/睡眠后继续活"的根本证明**，砍掉等于自欺。
- 连续 3 天：10-29 已有 action+稿+cf（预演 32/灵感）；10-30/31 各差一次自然行动。
- 没有任何一项被"等时间"卡死到无法并行开发——观测期禁改码是**观测协议**，不是开发停摆。
- 调整目标的唯一正当理由是"判据不可达"。目前判据全部可达，只是要等真实行动。**不调。**

## 2. C2 有没有更优方案？——没有

排除过的替代方案：
- **改系统时钟模拟**：违反"不伪造时间"铁律，且不能证明真实恢复。
- **只停 Cortico 不停看门狗**：tick 不断，空窗检查会 FAIL，等于没做。
- **缩短到 <8h**：26h 才触发记忆衰减（M1 范畴），8h+跨 04:00 是运行时恢复的最小真考验证，缩短就失去判别力。
- **用 --expect-offline 放行**：那是"预期离线"的显式声明工具，不是替代验证。
- 现方案（真实停 8h + tick 空窗 ≥8h + 强制终止覆盖 + 时钟回拨检查）已经是**最小可信集合**。

**唯一可优化的点**（不改变方案）：把 8h 窗口放在"她大概率不动"的时段，减少与自然行动冲突——现在已经这么做了（01:00–09:00）。

## 3. AMpath 值得吸收的模块（按目标相关度排序）

> 仓库：`E:/WorkSpace_Qoder/AMpath/packages/shared/src`。全部是纯函数 + 测试，许可干净（AMpath 私有，但我们是同作者）。AMpath 无 .git（快照拷贝），CHANGELOG 最后一次 session 2026-07-11，**没有"最近提交"可看，只有稳定快照**。

### 3.1 memory-reconstruction.ts（268 行）⭐ 最值得
**"每次回忆都是重构"**：按 vividness 分三级——高(>0.7)不变形、中(0.3-0.7)时间模糊/数字模糊、低(<0.3)只剩情绪印象。带 H3（CJK 正则不用 \b）、H5（对比效应保护：mood<-0.3 遇正面记忆减小偏差）、moodVolatility>0.3 禁用变形三条安全约束。原始记忆永不修改（只投影）。
**对小鱼的价值**：她现在的"记忆"是原文回放，没有失真。这直接回答了"她记不记得住、记得像不像人"。接入点：`persona-core/src/retrieval.ts` 的召回输出层，包一层 `reconstructMemory(memory, currentMood)`。**M4 级，纯函数，可独立测试，无上游耦合。**

### 3.2 field-engine/habituation.ts（133 行）⭐ 第二
正事件习惯化（0.9^N，地板 0.15x）、负事件敏化（min(1.1^N, 2.0) 上限）；NPC <7 天跳过；90 天重置窗口；系数记进 EffectBus source 供因果链追溯。
**对小鱼的价值**：她现在"看完喜欢的视频"每次 +0.12 刺激，第 100 次还是 +0.12——习惯化缺失正是 D-29（creativity 恒基线）的近亲。接入点：`applyEffects` 前按 `(source,field)` 查习惯化系数。**M1 级，133 行纯函数，接入成本低。**

### 3.3 field-engine/personality-lifecycle.ts（414 行）
涌现维度生命周期：30 天证据窗、5 天候选、14 天稳定、置信度 0.5±0.1 滑动。这是 Q-01（涌现维度做不做）的**现成实现**——之前三路盘点说"上游没有任何可用实现"，**这个盘点已过时**，AMpath 快照里有。
**对小鱼的价值**：不急于接（Q-01 仍是 NEED-USER），但"上游没有"这个论据要撤回。若未来批 Q-01=C，这就是起点，不用从零做。

### 3.4 engines/dream.ts（90 行，类型定义为主）
梦境引擎：基于记忆+情感生成梦，梦通过事件总线触发主动消息（"惊喜传递"）。90 行只是类型骨架，实现在 server 侧；但**"睡眠时做梦→醒来主动说"**这个机制跟她"睡着→醒来"的生活循环天然契合，是 P3 语音/主动消息的好素材。现在不接，留档。
