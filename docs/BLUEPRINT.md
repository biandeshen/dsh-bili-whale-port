## 2. 输入层缺失（原始研究漏项）

技术路线原先只讨论「移植 AMpath 哪些模块」，从没问**这些场值由谁来喂**。

- AMpath 是桌面伴侣：用户随时说话，`connection`/`social`/`stimulation` 被持续喂养。
- 小鱼是后台循环：唯一输入是「我看了个视频」。
- 实测闭环（2026-10-28 核）：World 8 个工具里**没有任何读私信/互动的工具**（`definition.ts` 工具清单）；`masterReplied` 是 `bili_mood_apply` 的 preset 字符串，**唯一"触发器"是模型自己填参数**；6 个 preset 中只有它给 `connection +0.10`；`decay.ts` 里 connection 速率为负、基线 0；`npc-state-machine` 要求 connection<0.3 持续 24h → `cold_war`，而出冷战需"user 发来消息"，同样无传感器。
- **结论**：`connection` 单向衰减 → 必然进 `cold_war` 且不可恢复，这是**数学必然，不是 bug**。30 天离线模拟 `connection=0.00 关系=cold_war` 即为此。

**输入层（Sensors）属于 L4，必须补**，否则 L3 人格内核只会单调衰减。

## 5. 唯一判据与结论

**判据：她自己醒来、过完一天、留下与昨天不同的痕迹。**
2026-10-27 15:49:27 **首次成立一半**——自主醒了（`restless`），但完整一天（醒→feed→debrief→写当天日记→出稿→mood_apply）尚未在一次自主唤醒内走完。连续天数为 0。

**结论**

1. **50 项里真正卡住全局的只有三项**：13 自主唤醒持续成立；17+21 输入层传感器（不补则 §2 的 cold_war 必然性无解）；29 记忆检索（不接则 memories 只是日志，不影响任何决策）。
2. **人格域不该继续堆项**。已有 5 项中，26 的频率门被我删过头、27 的 L1/L2 生产侧零调用。先把已有的接通并产生真实证据。
3. **自评不可信，外部判据才有效。** 三次外审（8.5/14 · 2/10 · 本轮曲解审计）抓到的都是"写了但没生效"或"写反了"。⚠ 8.5/14 与 2/10 的**原始报告从未落盘**，且同一分数在别处被写成"自评"，口径不一——以后外审结论必须落盘。
4. **我的失信模式已被证据化**：反复把主人的"限定条件/优先级/待办"升级为"否决/非目标"，并冠以"你已拍板"。v1 至少 7 处，见 §9。**这是本文件第 3 条纪律的由来。**
5. **流程最大缺陷是结论不落盘**：蓝图与 50 项清单此前只活在会被压缩的聊天里，被重新发明过两次。本文件即修复，但 v1 证明"落盘"本身不够——落盘内容必须逐条有出处。
