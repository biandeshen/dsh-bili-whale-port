## 1. 发送控制面（核心答案：可以配置，且默认保守）

现状盘点（已经生效的档位，2026-10-31 分级放开裁决）：

| 动作 | 现在怎么发 | 谁能叫停 |
|---|---|---|
| 动态（图文稿） | **永远人工**：她只出草稿，你在鱼缸页点 ✓ 才发 | 你不点 = 不发 |
| 回你私信 | 直发（互关/风控/冷却仍拦） | 配置可收回（见下） |
| 点赞/收藏 | 她自己发（判据+额度） | 配置可收回 |
| 评论/弹幕 | 进待审队列，你放行 | 不点 = 不发 |
| 全部写操作 | kill 开关一键熔断 | 最高优先级 |

要加的**发送策略配置**（世界页新增「发送策略」卡，写进 `worlds.bili-account` 配置节，WebUI 按声明渲染，不动框架）：

| 配置项 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `draftMode` | `review` / `auto` | **`review`** | auto = 她出稿后自动走同一条 publisher 发布（token 由服务端自绑，链路、限额、kill 全不变） |
| `autoWindow` | 如 `10:00-23:00`，空 = 不限 | 空 | 只在窗口内 auto；窗口外一律转人工队列 |
| `autoDailyCap` | 1–3 | `1` | auto 模式每日最多自动发几条 |
| `tierLike` / `tierFav` | on / off | on | 收回档位 = 回到待审队列 |
| `tierDmReply` | direct / queue | direct | 回信改回队列 = 每条等你点 |

红线（写进代码不写进口头）：
- **默认全人工**：auto 必须你显式打开，且有硬上限；关掉 auto 立即生效（下一个草稿就走队列）。
- kill 永远压过一切配置；`traffic` 412/冷却类失败**绝不重试成双发**（sending 状态机已锁）。
- 任何 auto 发布都照常写因果 + 面板留痕——你能随时看到"这条是自动发的"。

实现工作量：世界页一张配置卡 + `definition.ts` 草稿出口处分流 + 两条测试。**约半天，观测期外做**（改 World 要重启，明早 G3b 取证前不动 live）。

## 3. 全量功能规划（未来所有已知要做的事）

**A. 控制面与运营（最贴你日常）**
- 发送策略配置（上文 §1，你点头即做）
- 鱼缸页「今日一行总结」：她每天睡前列一句"今天我最想让你看到的事"（P0 活过来）
- 通知实弹：自主发言/待审/失败 → ntfy/bark 推到你手机（notify 模块已就位，差接通与测试）

**B. 她的生活更真（北极星主线）**
- Drive v2（模拟已备：零空日 + social/create 行动）——等你拍板
- 「存在感」微行为：路过你动态留个脚印级别的小事（行为改动，观测后）
- 关系推进：NPC 五态已有骨架，缺"事件驱动的关系变化"（冷战/回暖的实际触发）
- 词表回流实测（§2-4）——偏好学习要能在她选片里看见效果

**C. 表达力（图→声→视频）**
- M3a 形象：avatar manifest + 多帧状态（素材许可已盘：溟月 CC BY-NC-SA 限制多，序列帧仓库可用）
- M3b 语音接线：media/tts 已是独立层，World 出 `bili_voice`（她"说"一句）
- M3c 视频接线：video-build 薄壳完成 → World 出 `bili_video`（本地出片不投稿）→ 之后才谈视频发布器
- 按情绪选 BGM（catalog.mood 字段已埋）

**D. 平台与安全还债**
- dm-approve 迁 publisher（§2-5）
- 发布器错误分类细化（412/风控页 vs 网络 vs 业务码，给不同退避）
- 备份卫生：Cortico-local/dsh 双私有仓已就位；bundle 定期滚新
- 观测协议本体：14 天 `observe:day` + K4 复盘项

**E. 明确不做（除非翻案）**
- 自动关注/取关、公开评论区自发言（裁决挡着）
- AI 标识出戏声明（正文永远不出戏，披露只进简介）
- 一键审批绕过 token 的"快捷方式"
